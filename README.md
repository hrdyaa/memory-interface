# Memory Interface

A SystemVerilog project containing an SRAM model and an SPI master, with testbenches simulated using Icarus Verilog.

## Project Structure

- rtl/ — RTL design modules
- tb/ — SystemVerilog testbenches
- scripts/ — Simulation scripts
- logs/ — Regression output logs
- build/ — Generated simulation binaries

## Run Regression Tests

Run: ./scripts/run_iverilog.sh

## Tools

- SystemVerilog
- Icarus Verilog
- Git
